# Соответствие реализации исходной идее

Историческая матрица инженерного этапа 0.2.0.
Продолжение 0.3: [активный центр и дневник экспериментов](experiments/active-site-v3/README.md).
Новое продолжение P00947: [карточка реакции](experiments/active-site-v3/reaction-card-P00947.md),
[гипотезы](experiments/active-site-v3/mechanisms-P00947.md),
[статус поз](experiments/active-site-v3/poses-P00947.md) и
[журнал](experiments/active-site-v3/experiment-log.md). Скачок RMSD replica 101
объяснён периодическим образом; RMSF/DCCM и репличную статистику нужно пересчитать.
WT–ES и QM/MM-профиль остаются неподтверждёнными.
Локальные S/P P00947 совпадают со стереохимическими структурами PubChem по
InChIKey и isomeric SMILES; конкретный β-H предварительно назначен геометрически,
но требует независимой проверки атомного порядка и стереохимии
([журнал](experiments/active-site-v3/experiment-log.md)).
Две модели WT–5-AND минимизированы в TIP3P, один вариант с кислородами вод 8CHO;
они не валидированы, а прямая
парная энергия не является энергией связывания ([результат](experiments/active-site-v3/tools-and-complex.md)).
Radeon RX 550 обнаружен OpenCL после локальной установки, но полный комплекс
аварийно завершается на неподдерживаемом Rusticl; CPU остаётся основным backend.
[Аудит дополнительной минимизации модели 101](experiments/active-site-v3/minimization-audit-101.md)
не подтвердил сходимость; результат не является равновесным ансамблем.
Инструментированный restart v2 пока только предзарегистрирован: box будет
восстановлена из system.xml с разрешения пользователя, State XML отсутствует;
новая минимизация и PBC-аудит ещё не проведены.
Позднее для MD-pipeline выполнен ограниченный межмолекулярный PBC-аудит:
пар <1,5 Å в выбранных категориях нет. Последующий короткий NVT при 298,15 K
не прошёл энергетический критерий; из-за ошибки кода не остановился на 6 ps.
Этап 2 заблокирован; это не подтверждение готовности к эквилибрации.
Стартовая геометрия GLU43 сравнена с 8CHO; сравнительный свип ещё не выполнен.
Исходная идея из приложенного README включает шесть вычислительных блоков,
но её текст описывал желаемые возможности как уже выполненные. До этого этапа
проект имел обучаемый эмпирический baseline; физическая цепочка отсутствовала.
Процент близости без весов требований был бы произвольным.

## Выполненный план

1. Сверить идею с кодом, входными данными и фактическим окружением; убрать
   утверждения о несуществующих физически обоснованных расчётах.
2. Задать контракты единиц, конфигурации, результатов, кэша и ошибок.
3. Подключить реальные физические backend и безопасно объединить их в CLI.
4. Добавить микрокинетическую временную симуляцию, балансы и термодинамическую
   проверку; атомную трассировку и поле сохранить отдельным анализом.
5. Ввести семантические блоки, проекции и EC fallback; подключить физические
   таблицы к train/inference без использования целевых значений.
6. Проверить реальные расчёты на P00947, переобучить модели и провести
   разнесение по EC/имеющимся sequence clusters.
7. Зафиксировать артефакты, отрицательные результаты, тесты и эксплуатационные
   инструкции; сохранить v1 для сравнения и совместимости.

[Артефакты сравнения](benchmarks/v2/README.md).
Эти эксперименты исследовательские: прежние test уже просматривались,
EC-OOD использует другой состав test, поэтому числа разных split нельзя
считать прямой оценкой улучшения одной модели.

Покрытие pocket-признаков около 23–29% строк. QM batch выбрал 32 самых частых
SMILES без обращения к target: четыре успешны, 28 отклонены главным образом
из-за разъединённых реагентов. QM-покрытие kcat около 1.7%, Km — менее 1%.
Это слишком мало для заявления о полноценной квантовой модели всего датасета.
Missingness может отражать состав выборки и тоже требует ablation.

## Следующий научный цикл с измеримыми критериями

1. **Assay и единицы.** Для P00947 сверить первичный эксперимент, WT,
   олигомер, субстрат, kcat/Km, температуру, буфер, pH, ионную силу, кофакторы,
   погрешности. Приёмка: таблица assay с источником каждого значения; пропуски
   остаются явными. Значения из ML-датасета не заменяют первичный протокол.
2. **Подготовленный ES.** Использовать проверенный биологический димер и
   соответствующий субстрат. Обосновать протонирование, воду и параметры
   лиганда. Приёмка: согласованные PDB/System, отсутствие непараметризованных
   атомов, проверка зарядов/геометрии и независимый просмотр активного центра.
3. **Ансамбль.** Провести пилот производительности на этом CPU, затем несколько
   независимых seed после термализации. Приёмка: стабильные T/энергия,
   block analysis, autocorrelation/effective sample size и согласованные
   распределения, а не заранее выбранная длительность без проверки сходимости.
4. **Реакционная координата и свободная энергия.** Проверить TS/мнимую моду,
   путь реакции, QM-region и embedding; выполнить обоснованный umbrella/
   QM/MM-протокол со сходимостью. Приёмка: PMF/барьер с неопределённостью,
   sensitivity к QM-region и состояниям; электронная энергия не выдаётся за ΔG‡.
5. **Скорости и KIE.** Связать элементарные константы с полным циклом, проверить
   лимитирующие стадии, Haldane/равновесие и независимые скорости/изотопные данные.
   Приёмка: прогноз с доверительным интервалом, а не подгонка барьера по test-kcat.
6. **Обобщение ML.** Расширить физическое покрытие, независимо подготовить
   компоненты многосубстратных реакций и ESM-2; base/pocket/QM/MD/missingness
   ablation при одинаковых split и нескольких seed. Проверить исходное
   происхождение cluster assignments; при необходимости пересчитать на полном
   наборе последовательностей. Выделить новый внешний test и calibration set.
   Приёмка: воспроизводимое преимущество и проверенное покрытие интервалов,
   включая новые EC и низкое sequence identity.

Итог этого этапа — исполненная программная реализация исследовательского
контура и измеренные ограничения. Утверждение «реалистичная реакция со всеми
физическими эффектами и точным kcat из первых принципов» пока не подтверждено.
