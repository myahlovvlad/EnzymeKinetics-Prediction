# Аудит реакций kcat и границы механистического исследования

Первичный аудит локальных `kcat-random_trainval.csv` и `kcat-random_test.csv`.
Код: `enzyme-kinetics/scripts/audit_reaction_registry.py`; данные и карточки:
`enzyme-kinetics/outputs/reaction-registry-audit/`. Входные SHA-256 и версия
RDKit сохранены в `summary.json`. Источники не модифицируются.

## Результаты

- 23 151 строка, 12 266 уникальных исходных строк SMILES.
- 20 815 строк с двумя разбираемыми сторонами, 10 976 уникальных
  канонизированных направленных представлений среди этих строк.
- У 2 335 строк отсутствуют продукты; одна полная запись не разбирается RDKit.
  Ошибка парсинга не доказывает ошибку экспериментальной реакции.
- pH присутствует в 22 416 строках, температура — в 22 277, оба — в 21 851.
  Это полнота полей, не проверка корректности или единиц.
- Из 20 815 полностью разобранных строк 15 193 сбалансированы по элементам,
  16 932 по неводородным элементам, 16 964 по формальному заряду; одновременно
  по элементам и заряду — 13 554. Дисбаланс только по водороду — 1 739.
- Среди разобранных реакций 13 329 строк имеют хотя бы один неуказанный
  потенциальный тетраэдрический стереоцентр; это не полная проверка стереохимии.
  Размеченные атомы не найдены ни в одной из разобранных строк.

Это подсчёты **строк**, кроме явно обозначенных уникальных представлений;
не количество независимых экспериментов. Канонизация устраняет различия порядка
компонентов и учитывает сохранённую стереохимию, но не нормализует таутомеры,
протонирование или обратное направление. Химическая уникальность не доказана.

Баланс считается по указанным компонентам с кратностью их повторения,
с неявными H и формальным зарядом. Изотопы по отдельности не проверяются;
отсутствующие H+, вода, электроны или кофакторы не добавляются автоматически.
Дисбаланс H/заряда может отражать соглашение о протонном резервуаре;
баланс сам по себе не подтверждает идентичность, стереохимию и механизм.
В CSV нет полей буфера, ионной силы, концентраций, полной ссылки на assay
и единиц kcat. Поле sequence_source не является ссылкой на конкретный assay.

## Пилот P00947: гипотезы, а не результаты

Строки trainval 1526 и 9649 имеют одинаковый баланс элементов и заряда по
раздельности в исходных представлениях, но различаются записью стереохимии;
их нельзя объявлять независимыми повторами одного assay. Подтверждение
первичного источника и условий остаётся необходимым.

| Гипотеза | Проверяемое следствие | Статус |
|---|---|---|
| Последовательный перенос через диенолат с участием Asp38 | Два перехода, локальный минимум EI; KIE и мутационная чувствительность | Литературная рабочая гипотеза, не рассчитанный путь |
| Согласованный перенос без устойчивого EI | Один переход без свободноэнергетического минимума EI | Альтернатива для проверки; кинетическое отсутствие наблюдаемого EI не доказывает согласованность |
| Альтернативные протонные состояния и водный мостик | Отличие геометрий, pH-зависимости и энергетических барьеров | Гипотезы требуют подготовки микросостояний и протонного баланса |
| Иная ориентация субстрата / побочная реакция | Отличия контактных распределений, стереоспецифичности и продуктов | Не подтверждена; не предполагать существование побочного продукта |

## Статус этапов 3–6

WT 8CHO и аналоговые структуры имеются; продуктивный WT–ES не валидирован.
Исследованные короткие траектории — apo, не реакционные ES. Для replica 101
в `active-site-v3/replica-101/analysis.json` средний RMSD изменился с 0.0536
до 1.2328 nm между половинами. Причина неизвестна: проверить периодические
границы, выравнивание и траекторию до интерпретации как движения белка.

Полный TS/связность, QM/MM PMF, проверенная свободноэнергетическая сеть и
константы для KSI не получены. Существующий `physics/reaction.py` решает
упрощённый обратимый цикл с константами, заданными пользователем; он не является
микрокинетическим выводом констант KSI из расчётов. Без валидированного ES,
квантового пути и независимых констант нельзя честно считать этапы 3–6
выполненными. Отбор структур, масштабирование многосистемных расчётов и
проверка по базам/первичным статьям остаются отдельной работой.

## Воспроизведение

После восстановления окружения проекта:

```sh
uv run --locked python enzyme-kinetics/scripts/audit_reaction_registry.py \
  --input-dir enzyme-kinetics/data/Baseline/kcat \
  --output-dir enzyme-kinetics/outputs/reaction-registry-audit
uv run --locked pytest -q enzyme-kinetics/tests/test_reaction_registry_audit.py
```

Текущий `.venv/bin/python` ссылается на отсутствующий `/usr/bin/python3.13`;
фактический запуск использовал установленный отдельно Python 3.13 и существующий
site-packages, не меняя окружение. Данные outputs могут быть исключены из Git.
