# ADR 0001: расчётные блоки с явными научными контрактами

Статус: принято в рамках делегированной реализации шести блоков из задания.
Дата: 1 ноября 2026.

Сохраняются единый uv и пакет в enzyme-kinetics/src. Физические расчёты
выделяются в physics/, обучающие алгоритмы — в learning/. Независимые backend
возвращают версионированные JSON-артефакты и CSV-признаки с явными единицами,
статусом и provenance. Нативные тяжёлые зависимости входят в optional extras.

Решения: GFN2-xTB реализуется через Python tblite; MD — через OpenMM;
P2Rank/APBS запускаются аргументами subprocess без shell с ограничением времени;
PQR читается и проверяется; приближённая электростатика явно отличается от APBS.
Существующие сохранённые модели v1 должны оставаться загружаемыми.

Многоблочная PLS определяется математически через train-only стандартизацию,
нормировку блоков и PLS общего пространства, с отчётностью по блокам.
OPLS определена для скалярного y. Редкие EC-группы используют глобальную модель.
Ни одно название метода не служит доказательством улучшения качества.

Влияние: больше явных настроек и артефактов, зато нет скрытых замен отсутствующей
физики нулями. Количественный барьер/механизм конкретной реакции требует
отдельной научной валидации; автоматического обещания точного kcat нет.
