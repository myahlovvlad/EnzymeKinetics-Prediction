# Архитектура и контракты

## Границы

Один Python-проект uv управляет всем репозиторием. Устанавливаемый пакет
`enzymekinetics_prediction` находится в `enzyme-kinetics/src/`.
Корень содержит конфигурацию, документацию и CI; вложенный каталог — рабочий код.
`archive/`, большие `data/`, `outputs/` и `vendor/` не попадают в wheel.

Производственный исследовательский путь:

```text
CSV trainval -> групповой train/validation split
             -> fit FeatureBuilder / imputer / scaler только на train
             -> обучение и выбор checkpoint/гиперпараметров по validation
             -> фиксированный выбор модели
CSV test     -> transform -> однократная оценка всех фиксированных моделей
             -> аудит пересечения канонических пар -> отдельные очищенные метрики
```

`learning/features.py` не использует `value`, `log10_value`, производные target
или SMILES продукта. Признаки: состав и длина белка, Morgan fingerprint и
дескрипторы всех компонентов субстрата, T/pH с индикаторами пропуска,
имеющиеся 128-мерные эмбеддинги, сводки радиальных расстояний CA и EC.
EC vocabulary, заполнение пропусков и масштабирование обучаются только на train.

Предобученные эмбеддинги сопоставляются по UniProt из AF-/ESMFold-имени;
при двух вариантах приоритет AF. Их происхождение нельзя автоматически
называть ESM-2: текущий код использует имеющийся файл `progres` как готовые
векторы и сохраняет его SHA-256.

## Модели

- Среднее значение — нижний ориентир.
- Ridge и PLS — линейные и латентные базовые модели.
- HistGradientBoostingRegressor — нелинейная табличная модель.
- KineticsMLP — обучаемый регрессор 128 → 64 → 1.
- PhysicsAdd3DGraphNet — адаптация исходного радиального softmax-pooling
  с регрессионной головой и табличными признаками.

Последняя модель не содержит рёбер молекулярного графа, зарядов или QM/MM.
32 радиальных квантиля дают инвариантность к жёсткому движению, но теряют
направления и локальные взаимодействия. Её выход — log10 кинетического target,
а не энергия или вероятность посадки. Исходный необученный прототип сохранён
в `archive/legacy/graph_network_demo.py`.

## Входы и выходы

Для обучения обязательны `sequence`, `uniprot`, `ec`, `log10_value` и
`reactant_smiles` либо `substrate_smiles`. T/pH допускают пропуски.
Для inference target не нужен. Температура трактуется как °C, как в исходном
обучающем скрипте; единицы конкретного assay требуют сверки.

Все индикаторы отсутствия структуры/эмбеддинга и невалидного SMILES явные.
Лигандная геометрия не подменяет отсутствующую структуру фермента.
PDB учитывает только первый MODEL и подходящие CA altloc; SHA-256 каждого
использованного файла записывается отдельно.

Артефакты одного запуска: `metadata.json`, `metrics.json`, `split.csv`,
`predictions.csv`, `preprocessing.joblib`, модели `.joblib` и нейронные `.pt`,
истории обучения и `geometry_provenance.json`.
Нейронные файлы загружаются с `weights_only=True`; joblib предназначен для
доверенных локальных артефактов.

`experiments/` и Streamlit-приложение остаются иллюстративными исследованиями,
отдельными от обучения и inference. Скрипты P2Rank/ETL сохранены как инструменты
подготовки данных; таблица физических признаков теперь собирается `enzyme-features` и подключается явно.


## Контур 0.2

`physics/` владеет backend, единицами, кинетическими уравнениями и provenance;
`learning/` владеет регрессией и не превращает target в искусственный барьер.
Пайплайн конфигурации: structure/pocket → QM/PQR/MD → независимые sidecar-таблицы
→ FeatureBuilder → train-only preprocessing → projection/regression.
При группировке `grouped-three-way` объединение исходных CSV используется
только для нового явного разбиения, а не для прежней официальной test-оценки.

ConsensusMBPLS центрирует и нормирует каждый смысловой блок по training
Frobenius trace, затем выполняет PLS. OPLS удаляет вариацию X, ортогональную
скалярному y; EC-local модели обучаются только при достаточном числе train
наблюдений, иначе действует глобальная модель. Замороженные lookup физических
таблиц входят в preprocessing.joblib. Старые v1 checkpoint сохраняют прежний
набор признаков при загрузке.

Физика может генерировать координаты, поля и условные константы по заданным
барьерам. Отдельная обратимая mass-action модель проверяет балансы и Haldane.
Ни наличие backend, ни его связь с ML не означает найденного реакционного
механизма. Подробности: [ADR](adr/0001-physical-research-pipeline.md),
[физические протоколы](PHYSICS.md), [статусы требований](IMPLEMENTATION_STATUS.md).
