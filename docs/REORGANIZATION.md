## Удалено и почему

- Два устаревших/повреждённых окружения, пустые `modules/`, `config.yaml`,
  `run_pipeline.py` и пустой тест.
- Вложенные uv-конфигурации, дублирующий `requirements.txt` и вложенные
  настройки IDE. Единственные активные конфигурации находятся в корне.
- Установщик Miniforge: текущая установка использует uv.
- Оба одинаковых архива P2Rank: все 588 обычных файлов проверены по SHA-256
  против сохранённой распакованной поставки.
- Архив `capsule_data_update.tar.gz`, 10 207 582 747 байт: все **3 324** обычных
  файла совпали по SHA-256 с локальными данными; отсутствующих, отличающихся
  и неподдерживаемых членов не обнаружено. Проверен полный поток архива.
- Старая дублирующая реализация baseline заменена входом в общий обучающий код.
  Ridge/PLS сохранены, выбор модели по test устранён.

Суммарный размер удалённых файлов — около **12,43 ГБ** в десятичной системе.
Это логический размер файлов; показания свободного места могут отличаться.
Повторная копия эмбеддингов заменена относительной ссылкой на канонический файл,
поэтому старый путь провайдера остаётся доступным без хранения второй копии.

Подробности: [машинная карта изменений](CLEANUP_MANIFEST.json) и
[проверка архива](ARCHIVE_AUDIT.json).

## Исправления интеграции

Импорты используют устанавливаемый пакет; пути берутся из `paths.py`,
домашние абсолютные пути в активных утилитах заменены общими каталогами.
Импорт загрузчиков не запускает сеть или запись данных. PDB-тест использует
маленькую фикстуру и больше не проходит молча при отсутствии датасета.

В экспериментальном `estimate_kon()` исправлен перевод м³ в литры:
множитель `1e3` вместо `1e-3`. Для размерности добавлен независимый численный
тест. Этот модуль не участвует в обучении и не является валидированной
микрокинетической моделью.

В Streamlit убран переключатель с неподтверждённым обещанием DFT;
интерфейс явно обозначен как иллюстрация. Добавлены форматирование, линтер,
тесты и конфигурация GitHub Actions. CI подготовлен, но удалённый запуск
GitHub Actions в рамках этой работы не выполнялся.

Итог: 16 тестов, Ruff, сборка wheel/sdist и проверка зависимостей прошли.
Проверена загрузка обеих нейросетей для kcat/Km и совпадение сохранённых
предсказаний. [Машинная запись проверки](VALIDATION.json).
