# Анализ проекта — 31 октября 2026

## Вывод

Есть независимые прототипы химии, структурных признаков, визуализации и ML.
Готовность отдельных скриптов не означает готовность единого инструмента
предсказания кинетики. Основные препятствия: пустой структурный блок данных,
отсутствие обучения демонстрационной сети, несогласованная структура проекта
и недостаточная научная валидация.

## Научные ограничения

- Открытый скрипт строит молекулы; импорт `scf`, `grad`, `hessian` не выполняет
  соответствующие вычисления. Поиск переходного состояния, частотный анализ,
  термохимия и расчёт скорости ещё нужны.
- Условная поверхность EVB и ручной множитель туннелирования (`5.0` в
  `core_physics.py`) не являются квантовым расчётом барьера или KIE.
- Переключатель «High Accuracy» в Streamlit не вызывает DFT-расчёт.
- Барьеры и параметры демонстраций заданы вручную; связь с экспериментальными
  `kcat`/`Km` не валидирована.
- Единицы энергий, температур, концентраций и стандартные состояния нужно
  оформить как проверяемый контракт перед объединением физических модулей.

Численные физические формулы при настройке не изменялись. Исправлена ошибка
синтаксиса SMARTS в `experiments/core_chemistry.py`: разделитель продуктов `+`
заменён на `.`, сохранено атомное соответствие и задан спиртовой H. До исправления
существующий тест гидролиза находил 0 путей вместо 3. В тест добавлена проверка,
что оба продукта каждого пути парсятся RDKit.

## Уточнения автора и завершение настройки — 1 ноября 2026

Основной проект выбран: `enzyme-kinetics/`. Сначала создаётся исследовательская
документация, затем расчётный код. Направление — объединение физического
моделирования и хемометрики на данном ПК. Новая система выбрана по CSV: P00947;
подробности и основания в [docx](../enzyme-kinetics/docx/README.md).

Итоговое окружение использует системный Python 3.13.16. Управляемый 3.12.16
проходил RDKit/PySCF-проверки, но аварийно завершался при импорте pandas/PyArrow.
В финальной среде импорт всех установленных профилей успешен.
Точная низкоуровневая причина сбоя Python 3.12 не установлена.

Проверки: pytest — 6 passed; Ruff для новых диагностического скрипта и тестов —
успешно; uv pip check — зависимости совместимы; uv lock --check — успешно.
Исходный квантовый скрипт успешно выполнен на итоговом интерпретаторе.
ML/PyTorch, OpenMM, внешние QM/MD-двигатели, P2Rank/Java и полная симуляция
не установлены или не запускались; научная точность кинетики не проверялась.
