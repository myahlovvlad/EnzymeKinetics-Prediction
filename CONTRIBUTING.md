# Разработка

Используйте корневое окружение uv и Python 3.13.

```sh
uv sync --locked
uv run --locked ruff format enzyme-kinetics
uv run --locked ruff check enzyme-kinetics
uv run --locked pytest -q
uv build
```

Новые переиспользуемые вычисления добавляйте в `enzyme-kinetics/src/enzymekinetics_prediction/`,
CLI — в пакет или небольшие скрипты соответствующего раздела. Пути берите из
`paths.py`; не прописывайте домашний каталог и не меняйте cwd внутри библиотеки.
Импорт модуля не должен начинать загрузку данных, обучение или массовые расчёты.

Не добавляйте большие данные, веса, распакованные сторонние программы и кэши
в Git. Сохраняйте результаты в отдельный каталог запуска; указывайте seed,
версии, хеши входов, разбиение, preprocessing и ограничения.

Новые гиперпараметры выбирайте по validation. После просмотра test не выдавайте
его за нетронутую независимую проверку следующего исследовательского решения.
Сохраняйте отрицательные результаты ablation. Эмпирические регрессии,
декоративные анимации и механистические расчёты обозначайте отдельно.

Тесты должны проверять существенные контракты: отсутствие утечек, единицы,
инвариантности, загрузку артефактов и воспроизводимость предсказаний.
Датасет не нужен для обычных unit/integration-тестов: используйте маленькие
явные фикстуры. Полное обучение запускайте отдельным экспериментом.

Для изменения физических backend используйте `uv sync --locked --extra physics`
и `uv run --no-sync pytest -q`, чтобы сохранить optional dependencies.
Контракты и приёмка: [SDLC](docs/SDLC.md), [ADR](docs/adr/0001-physical-research-pipeline.md).
