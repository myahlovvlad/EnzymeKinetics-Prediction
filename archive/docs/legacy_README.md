## 📌 О проекте

Этот проект представляет собой гибридный вычислительно-биофизический ML-пайплайн для предсказания каталитической эффективности ферментов. В отличие от классических подходов «последовательность → число», мы переходим на уровень **настоящей вычислительной биофизики и квантовой химии**.

Мы не просто обучаем нейросеть на эмбеддингах; мы извлекаем физически осмысленные признаки: электростатический потенциал активного центра, квантово-химические свойства субстрата (граничные орбитали, энергии связей) и даже учитываем **эффект квантового туннелирования протонов**.

### 🔑 Ключевые принципы
1. **Механизм важнее последовательности:** анализ 3D-структуры и поиск каталитического кармана (P2Rank).
2. **Учет среды:** электростатика с учетом pH и сольватации.
3. **Квантовая природа катализа:** учет HOMO/LUMO, BDE и туннелирования (Kinetic Isotope Effect).
4. **Устойчивость на малых данных:** использование мультиблочной хемометрики (MB-PLS, OPLS) и EC-специфичных проекторов для борьбы с переобучением.

## ⚙️ Установка и зависимости

Проект использует [uv](https://github.com/astral-sh/uv) для управления зависимостями (Python 3.10+).

```bash
# 1. Клонирование репозитория
git clone <repo-url>
cd ENZYME-KINETICS

# 2. Создание окружения и установка зависимостей
uv sync
```

### Внешние инструменты (опционально)
Для полной функциональности пайплайна требуются:
*   **P2Rank** (уже включен в папку `prank/`)
*   **xTB** (для квантовых расчетов): `conda install -c conda-forge xtb`
*   **OpenMM / GROMACS** (для МД)

## 🚀 Использование

**Шаг 1. Подготовка данных и структур**
```bash
uv run python scripts/download_alphafold_pdbs.py
```

**Шаг 2. Поиск активного центра (P2Rank)**
```bash
uv run python scripts/run_p2rank.py
```

**Шаг 3. Извлечение физико-химических и квантовых признаков**
```bash
# Структурные признаки (диполь, гидрофобность)
uv run python scripts/extract_struct_features_advanced.py

# Квантовые признаки (HOMO-LUMO, BDE через xTB)
uv run python scripts/extract_qm_features.py
```

**Шаг 4. Обучение модели**
```bash
# Baseline (Ridge / PLS)
uv run python scripts/train_baseline_pls.py

# Модель с квантовыми признаками
uv run python scripts/train_qm_pls.py
```

## 🔬 Методология (Детали блоков)

### Блок 1: Идентификация активного центра
*   **P2Rank** предсказывает ligand-binding карманы без необходимости гомологии.
*   Извлекается список остатков, формирующих активный сайт.

### Блок 2: Электростатика и сольватация
*   **PDB2PQR** присваивает заряды с учетом pH (протонирование His, Asp, Glu).
*   **APBS / DelPhi** решают уравнение Пуассона-Больцмана для получения карты потенциала.

### Блок 3: Молекулярная динамика (МД)
*   Короткие симуляции (10–50 нс) комплексов фермент-субстрат.
*   Извлечение расстояний между донором и акцептором протона (критично для туннелирования), RMSD, DCCM.

### Блок 4: Квантовая химия и Туннелирование
*   **xTB (GFN2)**: расчет HOMO/LUMO gap, энергий диссоциации связей (BDE) и индексов Фукуи для субстратов.
*   **Поправка Белла**: учет квантового туннелирования протонов. В файле `equations.py` реализована функция `calculate_tunneling_coefficient()`, которая оценивает, насколько квантовые эффекты ускоряют реакцию по сравнению с классическим уравнением Эйринга.

### Блок 5: Признаки
*   Белковые эмбеддинги ESM-2.
*   Физико-химический профиль кармана (частота каталитических аминокислот).
*   Квантовые дескрипторы субстрата.
*   Условия (pH, T) и One-Hot EC-класс.

### Блок 6: Проекционная хемометрика (MB-PLS)
*   Использование **MB-PLS (Multiblock PLS)** для разделения вкладов белка, субстрата, условий и квантовых признаков.
*   **EC-специфичные проекторы:** обучение отдельной проекции для каждого класса ферментов (с fallback на глобальную модель для редких классов).
