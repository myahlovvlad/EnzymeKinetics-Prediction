# Работа с PDF

Перед анализом PDF преобразовывайте его в Markdown с помощью MarkItDown
(`markitdown[pdf]`) и читайте полученный Markdown. Сохраняйте исходный PDF
без изменений. Если вёрстка, таблицы, формулы или символы преобразованы
неоднозначно, дополнительно сверяйте соответствующие места с оригиналом или
независимым извлечением; не считайте Markdown гарантированно точной копией.
