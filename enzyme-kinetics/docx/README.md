# Исследование и постановка задачи

Дата: 1 ноября 2026. Основная кодовая база: `enzyme-kinetics/`.
Этот каталог называется `docx` по запросу автора. Исходники документов хранятся
в Markdown для проверки ссылок, истории изменений и последующего расширения.

Цель: сначала определить научно проверяемый протокол одной ферментативной реакции,
затем использовать расчётные признаки вместе с экспериментальными данными
для хемометрического прогнозирования. Реакционный симулятор на этом этапе
не реализован; документы описывают предлагаемый исследовательский маршрут.

## Основания

- Автор выбрал объединение физического моделирования и предсказания по данным.
- Используется только имеющийся ПК.
- Нужны траектории атомов/субстрата и анализ электростатики.
- Первая система должна отличаться от Q05469 и присутствовать в локальных данных.
- Рабочий выбор по результатам анализа — KSI `P00947`, EC `5.3.3.1`.
- Сначала исследование и документация; следующая реализация начинается
  после определения конкретного расчётного протокола.

В [evidence/pilot_records.json](evidence/pilot_records.json) сохранены исходные
записи выбранного фермента с номерами записей, хешами файлов и проверкой структуры.
[evidence/local_environment.json](evidence/local_environment.json) описывает
ресурсы, видимые текущей среде выполнения. Это не аппаратный бенчмарк.

## Текущее состояние реализации

Окружение единое, в корне репозитория. Из этого каталога uv находит его автоматически:

```sh
uv run --locked python scripts/diagnostics/check_environment.py --profile chemistry --profile quantum --profile dashboard --profile ml
uv run --locked pytest -q
uv run --locked enzyme-train --target kcat
```

Обучение эмпирических моделей kcat/Km уже выполнено. Это отдельный этап от
механистической симуляции P00947: QM/MM и расчёт наблюдаемого kcat из сети
элементарных переходов ещё не реализованы.
